# Changelog

## 1.0.0 — Initial public release

- Local finance dashboard, income/expenses, budgets and protected savings.
- Issued loan receipts, interest-first repayments, searchable Loan Records and
  three offline PDF lending reports.
- Inventory purchasing, FIFO costs, cash sales and profit reporting.
- Local authentication, duplicate-action protection, backups and schema migrations.
- Neutral configurable receipt identity and an entirely fictional opt-in demo.
- Windows launchers and automated synthetic-data regression tests.
